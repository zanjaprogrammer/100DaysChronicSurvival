# Art Direction & Visual Design Guide
## AI-Friendly Design for Unity 2D

---

## 🎨 Overall Art Style

### **Recommended Style: "Stylized Medical Illustration"**

**Why This Style?**
- ✅ Simple shapes = AI-friendly
- ✅ Clear silhouettes = readable gameplay
- ✅ Flat colors = easy to implement
- ✅ Educational feel = fits theme
- ✅ Scalable = works at any resolution

**Visual References**:
- Kurzgesagt (simple, flat, colorful)
- Cells at Work (anime style cells)
- Plague Inc (clean medical aesthetic)
- Monument Valley (geometric, clean)

---

## 🎯 Core Design Principles

### 1. **Simple Geometric Shapes**
- Circles, squares, triangles
- Minimal details
- Clear silhouettes
- Easy to recognize at small sizes

### 2. **Flat Color Palette**
- No gradients (atau minimal)
- High contrast
- Color-coded by type
- Consistent across game

### 3. **Readable at Small Scale**
- Game is 2D top-down
- Units will be small (32x32 to 64x64 pixels)
- Must be recognizable instantly
- Strong silhouettes essential

### 4. **Consistent Style**
- All assets follow same rules
- Same line weight
- Same color saturation
- Same level of detail

## 🛠️ Technical Specifications

### **Sprite Sizes**:
- **Small units**: 32x32 to 40x40 px
- **Medium units**: 48x56 px
- **Large units**: 64x80 px
- **Bosses**: 128x128 px
- **UI cards**: 400x600 px
- **Icons**: 24x24 or 32x32 px

### **Export Settings**:
- **Format**: PNG with transparency
- **Resolution**: 2x or 4x for retina displays
- **Compression**: Lossless
- **Color Mode**: RGBA

### **Unity Import Settings**:
- **Texture Type**: Sprite (2D and UI)
- **Pixels Per Unit**: 100 (standard)
- **Filter Mode**: Point (for pixel art) or Bilinear (for smooth)
- **Compression**: None or Low Quality
- **Max Size**: 2048 or 4096

## 📝 AI Generation Tips

### **For Best Results**:

1. **Be Specific**:
   - Include "2D game sprite"
   - Specify "top-down view"
   - Mention "transparent background"
   - State exact pixel size

2. **Style Consistency**:
   - Always mention "flat colors"
   - Always mention "clean lines"
   - Always mention "medical illustration style"
   - Keep same art style across all prompts

3. **Iteration**:
   - Generate multiple variations
   - Pick best one
   - Refine with more specific prompts
   - Keep successful prompts for consistency

4. **Post-Processing**:
   - Clean up in image editor if needed
   - Ensure transparent background
   - Resize to exact specifications
   - Add outline if missing

### **Recommended AI Tools**:
- **DALL-E 3**: Best for consistent style
- **Midjourney**: Great for stylized art
- **Stable Diffusion**: Most control
- **Leonardo.ai**: Game asset focused
