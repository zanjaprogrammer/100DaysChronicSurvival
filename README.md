# 100 Days Chronic Survival

## 🎮 Game Overview
Educational roguelike auto-battler game tentang bertahan hidup dari 3 penyakit kronis: **Diabetes**, **Hipertensi**, dan **Kanker**. Tubuh adalah battlefield, immune cells adalah army-mu!

## 🎯 Core Concept
- **Genre**: Roguelike Auto Battler + Educational
- **Platform**: PC (Unity 2D)
- **Target**: 100 days survival
- **Theme**: Body as battlefield, lifestyle as strategy

## ✨ Key Features
- 🦠 **14 Body Components** yang saling terhubung
- 💉 **10+ Immune Cell Types** dengan unique abilities
- 🧬 **3 Disease Systems** dengan distinct mechanics
- 🎴 **30+ Lifestyle Cards** untuk strategic choices
- 🗺️ **5+ Organ Arenas** dengan unique mechanics
- 🎨 **Procedural Neon Blobs** untuk visual yang dynamic
- 📚 **Educational Content** terintegrasi dalam gameplay

## 🎮 How to Play (Planned)
1. **Battle Phase**: Place immune cells, watch auto-battle
2. **Card Selection**: Choose 1 of 3 lifestyle cards
3. **Random Event**: Body makes random decision
4. **Repeat**: Survive 100 days!

## 🚀 Getting Started

### Prerequisites
- Unity 2021.3 LTS or newer
- Git

### Setup
1. Clone repository
2. Open `ChronicSurvival/` folder in Unity
3. Wait for Unity to import assets
4. Open `SampleScene` in `Assets/Scenes/`
5. Press Play!
